## New project: Agentic Meal Planner

Repo: https://github.com/swizzleshizzle/AgenticMealPlanner — "An Open Source Hello Fresh Alternative" (Apache-2.0, TypeScript, actively developed).

### Live preview decision

**No live demo.** The app is full-stack (React 18/Vite/Tailwind 4 client + Express 5/Prisma/PostgreSQL 16 server + Claude Agent SDK) and intentionally ships with no authentication — README/SECURITY.md restrict it to trusted private networks. GitHub Pages hosts static files only, and any public hosting would expose an unauthenticated app wired to a paid Anthropic API key. Card links: `githubLink` → repo; `link` → repo (same), no `embed`.
